Sobre este projeto

O Alternativas Gratuitas para Fontes Premium e um guia pratico que ajuda designers e desenvolvedores a encontrar substitutos gratuitos do Google Fonts para fontes premium populares.

O projeto oferece uma tabela completa com mais de 57 fontes premium mapeadas para suas melhores alternativas gratuitas, alem de uma ferramenta de comparacao visual lado a lado para avaliar a semelhanca entre as fontes.

Todas as fontes alternativas estao disponiveis gratuitamente atraves do Google Fonts, tornando-as acessiveis para qualquer projeto web.

Criado por Guilherme Gonzalez — Todas as alternativas estao disponiveis gratuitamente no Google Fonts.
